# Demo Recording Checklist

## Before recording

- [ ] Close notifications, email, chat, and unrelated browser tabs.
- [ ] Use a clean terminal theme and a readable 18–20px font.
- [ ] Confirm `demo.py` runs from start to finish.
- [ ] Confirm the terminal shows `Catalog products: 50,000` and `Local semantics: enabled`.
- [ ] Prepare one architecture view and one results view.
- [ ] Replace the closing-slide GitHub placeholder.
- [ ] Rehearse once with a timer; target 2:45–2:55.

## During recording

- [ ] Show the command being executed.
- [ ] Point out the turn-two ranking change.
- [ ] Point out that waterproof is removed on turn three.
- [ ] Highlight `material=leather`, `color=black`, and `style=casual`.
- [ ] Show the first black leather result and response time.
- [ ] State that runtime network, API calls, tokens, and cost are zero.
- [ ] Mention the full public result and deterministic fallback.

## After recording

- [ ] Duration is no more than 3:00.
- [ ] Text remains readable at YouTube 1080p.
- [ ] Audio is clear and has no private background content.
- [ ] YouTube visibility is Public.
- [ ] Video plays without sign-in in an incognito window.
- [ ] YouTube URL is added to Devpost and the repository README.
